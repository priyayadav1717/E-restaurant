# 🍔 Eatzilla

Eatzilla is a responsive food ordering web application built with HTML, CSS, JavaScript, and PHP. It provides an intuitive interface for exploring food categories, browsing menu items, and placing orders. The project combines a modern front-end with a PHP-powered backend to deliver a seamless and interactive user experience.

## Features

* 🍕 Browse food categories and menu items
* 🛒 Interactive food ordering interface
* 📱 Fully responsive design for all devices
* 🔧 Backend functionality powered by PHP
* 🎨 Modern and user-friendly UI
* ⚡ Smooth navigation and fast performance

## Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** PHP
